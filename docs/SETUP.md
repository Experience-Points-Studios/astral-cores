# Setup

## 1. Download Astral Cores

Download the latest version of [Astral Cores](https://modrinth.com/mod/astral-cores) and install it on your server.

Make sure [Fabric API](https://modrinth.com/mod/fabric-api) is also installed on the server.

## 2. Start the Server

Start your server and join it with your Minecraft client.

You do not need to install Astral Cores on your client.

## 3. Give Yourself Operator Permissions

Give yourself operator permissions so you can run the setup commands.

You can do this from the server console with:

```text
/op <player>
```

Replace `<player>` with your Minecraft username.

## 4. Place the Altar

Once you are in game, stand at the location where you want the altar to be placed and run:

```text
/astralcores place altar ~ ~ ~
```

The altar will be placed at your current position. This is where the Cores will respawn.

If you place the altar incorrectly, run:

```text
/astralcores remove altar
```

Then break the altar and place it again at the correct location.

## 5. You're Done

The server is now set up and ready to use.

For an overview of Astral Cores and links to all season documentation, see the [Main Readme](https://github.com/Experience-Points-Studios/astral-cores/blob/main/README.md).
